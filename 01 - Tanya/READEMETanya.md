Tanya is an OS that uses text as image, u can use the arrows to move, enter to select anything u want and every app have something:
Terminal -> It has some comands, type Help for the list
Snake -> It's the snake game, if u press 'w' it becomes slower and if u press 's' it becomes faster
Calculadora -> it's a simple calculator, first u type the first num, press enter, type the second, press enter, type +, -, / or * and it'll show u the result
Files -> you'll se four apps in it, write, draw, zimgs and texts, texts and zimgs shows the images or texts that u already have, if you have defined a password and the file is protected it will request it
at draw you can draw your own image, with 'w' and 's' you can change the color, press select and you will paint a square, hold shift and every square that u pass will get painted, press esc and it will save the file
at write you can write your text files, with also protection or not
